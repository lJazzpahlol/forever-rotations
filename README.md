# Forever Rotations

Download repository for World of Warcraft Forever rotations.

This repository holds **encrypted builds only**. Each rotation is a ZIP in the
[`forever-live` release](https://github.com/lJazzpahlol/forever-rotations/releases/tag/forever-live),
listed with its version, changelog and SHA-256 fingerprint in `manifest.json`
on the same release. No source code is published here.

## Install

1. Download the rotation's ZIP from the `forever-live` release.
2. Extract it into your Inferno `Rotations\Forever` folder. Each ZIP contains
   one folder, for example `Forever Priest AIO Leveling\rotation.in`.
3. Select the rotation in Inferno.

If a release note says settings changed, delete `save.xml` (or `save.dat`) in
that rotation's folder so the new options appear.
